# Fonts

All three faces are self-hosted (never fetched at runtime) so the app renders offline and a webfont
request never costs Supabase egress. Latin subsets, as served by Google Fonts.

- **Bricolage Grotesque** — Mathieu Triay. SIL Open Font License 1.1.
- **Instrument Sans** — Rodrigo Fuenzalida, Jordan Egstad. SIL Open Font License 1.1.
- **IBM Plex Mono** — IBM. SIL Open Font License 1.1.
